# DDI-PI1-Brenisva-2025
CO Data  

La aplicación COData (Cajeme Open Data) sería una plataforma diseñada para gestionar y registrar reportes ciudadanos en el municipio de Cajeme (que incluye la ciudad de Obregón, Sonora). Su objetivo principal sería facilitar la comunicación entre los ciudadanos y el gobierno municipal, permitiendo un seguimiento de las solicitudes.
